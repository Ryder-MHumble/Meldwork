# Meldwork 宣传视频脚本

本文提供一支 75 秒产品主片的中文与英文版本，并说明如何从同一批录屏素材中拆出 README GIF、30 秒短片和 15 秒预告。

核心叙事：

> **一个任务，两种视角，一份用户能够检查的结果。**

视频不强调 Agent 数量，也不把未来能力包装成当前功能。所有主画面都来自真实客户端操作。

## 一、创意方向

### 目标观众

- 已经同时使用两种以上 Agent 的开发者、研究者、产品经理和独立创作者。
- 对多 Agent 概念感兴趣，但反感角色扮演、无限对话和不可检查结果的人。
- 希望保留本地工作状态、明确文件权限并继续使用现有 Agent 与 Provider 的用户。

### 看完后只需记住三件事

1. Meldwork 让一项任务在不同 Agent 之间保持完整。
2. 多 Agent 协作有明确参与者、上下文和轮次边界。
3. 最终结果不是黑盒，用户可以检查后再决定。

### 视觉风格

- 16:9 横屏，优先 `3840 × 2160` 或 `2560 × 1440`，24 或 30 fps。
- 以真实产品录屏为主，使用深色或中性背景、白色文字和少量品牌珊瑚色。
- 每个镜头只突出一个动作：选择、附加、讨论、检查或决定。
- 字幕使用 Inter、SF Pro 或思源黑体，字距为 0，不使用夸张描边。
- 转场以硬切、轻微推近和界面动作匹配为主，不使用粒子、机器人、发光球体或通用 AI 动画。
- 音乐选择克制的电子氛围与轻节拍；不使用电影预告式重击和连续上升音效。

### 画面结构

| 时间 | 视觉任务 |
| --- | --- |
| 0:00-0:06 | 说明“拥有多个 Agent”不是难点 |
| 0:06-0:14 | 从一个 Agent 开始，按需增加另一个 |
| 0:14-0:25 | 选择 Agent、工作目录和权限边界 |
| 0:25-0:36 | 加入必要文件、Skill 或知识来源 |
| 0:36-0:51 | 设置轮次上限并展示有界讨论 |
| 0:51-1:06 | 检查 Agent、轮次、上下文、结论和事件 |
| 1:06-1:15 | 人保留最终决定，品牌收尾 |

## 三、中文 75 秒主片

### 0:00-0:06｜问题

**画面**

快速切过三个不同 Agent 的独立窗口或 Logo，随即切到 Meldwork 中的一项未完成任务。画面不超过三次切换。

**旁白**

> 现在，找到一个能回答问题的 Agent 很容易。难的是，切换 Agent 之后，这项工作还能不能保持完整。

**屏幕字幕**

> 让任务保持完整

### 0:06-0:14｜从一个 Agent 开始

**画面**

打开一个历史单聊，显示此前结论；用户发送继续任务的消息，Agent 行内开始响应。

**旁白**

> 在 Meldwork，你先从一个 Agent 开始。只有当任务需要另一种能力或独立质疑时，才把第二个 Agent 加进来。

### 0:14-0:25｜先确定边界

**画面**

创建群组，选择两个 Agent，选择演示工作目录，写入开关保持关闭。镜头依次轻微推近三个动作。

**旁白**

> 选择参与者、工作目录，并决定是否允许写入。任务开始前，边界清楚可见。

**屏幕字幕**

> 选择 Agent，设定边界

### 0:25-0:36｜加入必要上下文

**画面**

附加 `architecture.md` 与 `tests.md`，短暂展示 Skill 或已经就绪的知识来源入口。若知识来源未稳定配置，只使用文件附件画面。

**旁白**

> 只加入这次任务真正需要的文件、Skill 和知识来源。上下文不再靠每次切换后重新拼接。

**屏幕字幕**

> 只加入必要上下文

### 0:36-0:51｜设置轮次上限

**画面**

切换到自动讨论，把“最大轮数”设为 2。展示两个 Agent 依次响应、第 1 轮切换到第 2 轮，以及第 2 轮完成。

**旁白**

> 给两个 Agent 设置清晰的轮次上限，让它们先提出观点，再质疑和修订。目的不是增加声音，而是减少没有被发现的假设和错误。

**屏幕字幕**

> 设置轮次上限

### 0:51-1:06｜检查运行证据

**画面**

打开 Run 详情，切换 Agent 与轮次，展开结论、注入的上下文来源、上下文计数和脱敏事件。每个区域停留约 1 秒，避免快速扫过。

**旁白**

> 打开运行详情，你可以看到每个 Agent、每一轮、注入的上下文来源与数量、形成的结论和脱敏事件。先检查结果，再决定是否相信和采用。

**屏幕字幕**

> 验收前先检查

**事实说明**

> 工作空间状态保存在本机；Agent 请求由所配置的 Provider 处理。

### 1:06-1:15｜人的最终决定

**画面**

关闭 Run 详情，切换到“单轮回答”，只点名一个 Agent 生成最终修订。随后淡出到 Meldwork 标志、产品名与 Slogan。

**旁白**

> 最终决定仍然属于你。Agent 随时切换，工作始终连续。Meldwork。

**收尾画面**

> Meldwork
> Agents change. Work continues.

## 四、English 75-Second Master

### 0:00-0:06 | The problem

**Visual**

Cut across three separate Agent surfaces, then land on one unfinished task inside Meldwork. Keep the sequence restrained and readable.

**Voice-over**

> Finding an Agent that can answer a question is easy. Keeping the work coherent when you switch Agents is not.

**On-screen text**

> Keep the task together.

### 0:06-0:14 | Start with one Agent

**Visual**

Open an existing direct conversation, reveal the last confirmed decision, and send a continuation request. Show the inline run state.

**Voice-over**

> In Meldwork, you start with one Agent. You add another only when the task needs a different capability or an independent challenge.

### 0:14-0:25 | Set the boundary

**Visual**

Create a group, choose two Agents, select the demo working folder, and keep workspace writes off.

**Voice-over**

> Choose the participants and working folder, then decide whether workspace writes are enabled. The boundary is visible before the task begins.

**On-screen text**

> Choose the Agents. Set the boundary.

### 0:25-0:36 | Add necessary context

**Visual**

Attach `architecture.md` and `tests.md`. Briefly reveal a compatible Skill or a configured knowledge source only when it is ready on the recording machine.

**Voice-over**

> Add only the files, Skills, and knowledge sources this task needs. Stop rebuilding context every time the work moves.

**On-screen text**

> Add only the context needed.

### 0:36-0:51 | Set a round limit

**Visual**

Select automatic discussion, set the maximum round limit to two, and show the Agents completing round one and round two.

**Voice-over**

> Give two Agents a clear round limit so they can propose, challenge, and refine. More voices are not the goal. Fewer unchecked assumptions are.

**On-screen text**

> Set the round limit.

### 0:51-1:06 | Inspect the work

**Visual**

Open Run details. Switch between Agents and rounds, then reveal conclusions, injected source messages, context counts, and sanitized events.

**Voice-over**

> Open Run details to inspect each Agent, each round, the injected source messages and context counts, the conclusions reached, and the sanitized event history. Inspect the work before you trust the result.

**On-screen text**

> Inspect before accepting.

**Factual lower-third**

> Workspace state stays local. Agent requests use your configured Provider.

### 1:06-1:15 | Make the final call

**Visual**

Close Run details, switch to Single response, target one Agent for the final revision, then fade to the Meldwork mark, wordmark, and slogan.

**Voice-over**

> The final decision stays with you. Agents change. Work continues. Meldwork.

**End frame**

> Meldwork
> Agents change. Work continues.

## 五、声音与剪辑

### 音乐

- 开头使用低频但轻量的脉冲，不做紧张悬疑。
- 选择 Agent、目录和附件时加入非常轻的界面触感音。
- 自动讨论开始时加入一个短促节拍，不为每条消息重复音效。
- 打开 Run 详情时减弱音乐，让旁白和界面信息更清楚。
- 结尾不做大幅上扬，只保留一个干净的收束音。

### 节奏

- 前 6 秒最多 4 个镜头。
- 6-36 秒每个操作镜头保持 2-4 秒。
- 自动讨论过程允许加速，但 Agent、轮次和完成状态必须可辨认。
- Run 详情禁止快速滚动；每个检查点至少停留 1 秒。
- 品牌收尾保持 2.5-3 秒，给观众留下识别时间。

### 字幕

- 全程字幕，但每行不超过 18 个中文字符或 42 个英文字符。
- 旁白字幕靠下；核心屏幕字幕位于画面左上或留白区，二者不要重叠。
- 不在画面上解释产品设计方法，也不加入“如何阅读本视频”的说明。

## 六、30 秒精简版

从主片保留四段：

1. `0:00-0:06`：Agent 容易找到，工作容易被切碎。
2. `0:14-0:25`：选择 Agent、目录与权限。
3. `0:36-0:51`：两轮上限与讨论过程压缩为 8 秒。
4. `0:51-1:15`：检查运行详情与品牌收尾压缩为 10 秒。

中文结尾旁白：

> 不要只收集更多回答。让一项工作保持完整，并在接受之前看清它。Meldwork。

English ending:

> More answers are not the goal. Keep the task coherent. Inspect the result before you accept it. Meldwork.

## 九、上线前检查

- [ ] 所有功能都能在当前录制环境中重复执行。
- [ ] 视频没有暗示自动组队、统一检索、Cloud Agent 或 Channel 已经可用。
- [ ] 本地优先说明同时交代 Provider 请求边界。
- [ ] 写入权限、路径、附件和知识来源没有泄露真实数据。
- [ ] Run 详情中没有凭据、原始思维链、完整命令或原生 Session 标识。
- [ ] 中英文旁白表达同一事实，没有一版比另一版做出更强承诺。
- [ ] 品牌名、Logo、Slogan 和珊瑚色端点在所有版本中一致。
- [ ] 结尾把最终决定留给用户，不把 Agent 共识包装成正确性保证。
