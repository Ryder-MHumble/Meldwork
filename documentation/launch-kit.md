# Meldwork Launch Kit

This document contains draft public-relations and repository-launch copy. Do not publish the open-source claims until a license is committed.

## Positioning

**Category:** Open-source, local-first multi-Agent collaboration workspace

**Tagline:** Put your local agents to work, together.

**One sentence:** Meldwork brings the AI coding Agent CLIs already on your computer into one persistent workspace, where they can contribute, challenge, and continue the same task while orchestration stays local.

**Chinese:** Meldwork 是开源、本地优先的多智能体协作工作台，让不同 Agent 围绕同一任务共同产出。

Meldwork brings the AI coding agents already on your computer into one shared task. Let Codex, Claude Code, Kimi Code, MiMo Code, Gemini CLI, OpenCode, Qwen Code, and other local CLIs contribute, challenge, and continue each other's work while orchestration stays on your machine.

## Chinese Announcement

Meldwork 把电脑中已经安装的编码 Agent CLI 汇聚到同一个任务中。Codex、Claude Code、Kimi Code、MiMo Code 等 Agent 可以在持续会话里提出方案、交叉审查并继续彼此的工作，群组、消息与编排仍保留在本机。

## Story Structure

1. Developers already use several capable Agent CLIs, but their context and sessions are scattered.
2. Meldwork gives those existing Agents one persistent local workspace.
3. A real demo should show one task moving from proposal to challenge, revision, and finished output.
4. The product difference is heterogeneous CLIs, native-session continuity, local orchestration, and explicit permission boundaries.
5. Local-first does not mean every model is offline; selected Providers may still use the network.
6. The open-source call to action should ask for Agent adapters, installation compatibility reports, Skills, and real-device validation.

## Pull Request Summary

### What changed

- Rebranded the user-facing product from RoundRelay to Meldwork.
- Introduced an asymmetric open-braid identity with separate transparent navigation, app-icon, and favicon assets.
- Replaced the industrial onboarding imagery and aligned the bilingual onboarding copy with local multi-Agent collaboration.
- Added MiMo Code CLI support in read-only plan mode and moved Qwen Code to the end of the Agent list.
- Refined the conversation workspace without changing the narrow Electron preload boundary or local storage compatibility identifiers.

### Why

The new name and visual system make the product category clearer, reduce the Mac/MAC ambiguity in the earlier naming direction, and better express multiple independent Agents combining their work without implying a closed or symmetric system.
